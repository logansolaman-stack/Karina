# Karina

Repository for all work done by Karina AI assistant.

## Purpose
This repository serves as the central location for all files, documentation, and work products created by the Karina AI assistant. All future work will be organized and stored within this repository.

## Structure
- `/docs` - Documentation and guides
- `/projects` - Project files and code
- `/notes` - Meeting notes and miscellaneous notes
- `/scripts` - Automation scripts and tools

## Usage
All work performed by Karina will be organized and stored within this repository according to the established directory structure.

## Configuration
See `.config/work-organization.md` for detailed workflow instructions.
